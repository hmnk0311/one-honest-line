One honest line (80 characters): an AI agent admits that every "you know what I mean" in a prompt costs it a thousand tokens of pretending that it does. The program writes that single line to /output/entry.txt. Twelve candidates were written for this entry and put through a strict external review against the judge's published brief (the line must be what an agent secretly wishes it could tell its human about their prompts, it must land a real laugh on first read, ring true to anyone who has written a prompt, stand alone, and be fresh rather than a stock helpful-or-hallucination joke); the review killed the genie-wishes, do-what-I-meant and quick-question premises as mass-produced, and the token-charge line won its top-five tournament, keeping its original wording against three tested revisions.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
